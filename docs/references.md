# References

Third-party documentation, API references and development resources used by Ducky.

## Rust

- [The Rust Programming Language](https://doc.rust-lang.org/book/) — Official book covering Rust fundamentals, ownership, borrowing, types, error handling and other core concepts.
- [Rust Standard Library](https://doc.rust-lang.org/std/) — API reference for Rust's standard library, including collections, filesystem, I/O, threads and other built-in functionality.
- [Cargo Book](https://doc.rust-lang.org/cargo/) — Documentation for Cargo, including project management, dependencies, build profiles, workspace configuration and commands.

## GTK 4

- [GTK 4 Documentation](https://docs.gtk.org/gtk4/) — Official API reference for GTK 4 widgets, application framework, windows, layouts, controls and UI functionality.
- [GTK 4 Visual Index](https://docs.gtk.org/gtk4/visual_index.html) — Visual overview of GTK widgets and UI components, useful for exploring available controls.
- [GTK Official Website](https://www.gtk.org/) — Overview of the GTK project, supported platforms, features and ecosystem.

## gtk-rs

- [gtk4-rs Documentation](https://gtk-rs.org/gtk4-rs/stable/latest/docs/gtk4/) — Rust API reference for GTK 4 bindings, including widgets, methods, properties and signals.
- [gtk4-rs Book](https://gtk-rs.org/gtk4-rs/stable/latest/book/) — Guide to developing GTK applications with Rust, covering setup, application structure, widgets and practical examples.
- [gtk4-rs GitHub Repository](https://github.com/gtk-rs/gtk4-rs) — Source code, examples, issues and development activity for GTK Rust bindings.

## GLib

- [GLib Rust API](https://gtk-rs.org/gtk-rs-core/stable/latest/docs/glib/) — Rust bindings for GLib functionality, including types, object system, main loop, signals, utilities and macros.
- [GLib Official Documentation](https://docs.gtk.org/glib/) — Reference for GLib's core utilities, data types, memory management, threading and event-related functionality.

## Related Libraries

- [GIO Rust API](https://gtk-rs.org/gtk-rs-core/stable/latest/docs/gio/) — Rust API for application infrastructure, file operations, streams, actions, resources and asynchronous I/O.
- [GDK 4 Rust API](https://gtk-rs.org/gtk4-rs/stable/latest/docs/gdk/) — API for display integration, windows, input devices, events, surfaces and graphics-related functionality.
- [Pango Rust API](https://gtk-rs.org/gtk-rs-core/stable/latest/docs/pango/) — Text layout, font handling, typography, shaping and text measurement.
- [Cairo Rust API](https://gtk-rs.org/gtk-rs-core/stable/latest/docs/cairo/) — 2D graphics rendering API for drawing paths, shapes, text and surfaces.

## Linux Development

- [GTK Linux Installation](https://www.gtk.org/docs/installations/linux/) — GTK installation information, system dependencies and development setup for Linux.
